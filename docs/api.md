# إضافة واجهة التطبيق (API)

إضافة `api` توفر واجهة JSON **عامة وللقراءة فقط** تحت `/api/v1/…` ليستهلكها تطبيق الجوال النيتف. لا تنشئ أي جداول، وتقرأ من جداول الإضافات الأخرى فقط، وتحترم حالة كل إضافة (المعطَّلة ترجع خطأ لطيفًا) وحالة النشر (المحتوى المنشور فقط). لا تعرض أبدًا بيانات جوال العائلة أو القائمة البريدية أو أي بيانات إدارية.

كل الاستجابات بالشكل:

```json
{ "ok": true, "data": { … } }
{ "ok": false, "error": "رسالة" }
```

روابط الوسائط تُرجَع مطلقة: `{ "url": "…", "thumb": "…" }`.

## المسارات

| المسار | الوصف |
|---|---|
| `GET /api/v1/app` | هوية الموقع: الاسم، الشعار، ألوان القالب، الإضافات المفعّلة، المدن |
| `GET /api/v1/home` | محتوى الرئيسية: إعلانات، أقرب مناسبة، قادم قريبًا، أخبار، جمعات، لمحات معرض |
| `GET /api/v1/news?page=&per_page=&category=` | قائمة الأخبار المنشورة + التصنيفات (مع ترقيم صفحات) |
| `GET /api/v1/news/{slug}` | تفاصيل خبر: المحتوى HTML، الصور، الوسوم، أخبار ذات صلة، رابط مشاركة |
| `GET /api/v1/calendar?scope=upcoming|past&limit=` | مواعيد الرزنامة المنشورة |
| `GET /api/v1/gatherings?city=` | الجمعات النشطة + المدن وعدد جمعاتها |
| `GET /api/v1/gallery?page=` | ألبومات المعرض المنشورة (غلاف كل ألبوم: المحدد أو أول صورة) |
| `GET /api/v1/gallery/{slug}` | صور الألبوم |
| `GET /api/v1/obituaries` | الوفيات (النشطة أولًا) |
| `GET /api/v1/poetry` | الشعراء النشطون وعدد قصائدهم |
| `GET /api/v1/poetry/{id}` | قصائد الشاعر المنشورة |
| `GET /api/v1/archive?page=&category=` | مواد الأرشيف المنشورة + التصنيفات |
| `GET /api/v1/archive/{slug}` | تفاصيل مادة أرشيفية مع ملفها |
| `GET /api/v1/tree` | عقد شجرة النسب الظاهرة (قائمة مسطحة `id/name/parent_id`) |
| `GET /api/v1/pages` | الصفحات الثابتة المنشورة |
| `GET /api/v1/pages/{slug}` | محتوى صفحة (HTML) |
| `GET /api/v1/announcements` | الإعلانات النشطة (كل المواضع) |
| `GET /api/v1/search?q=` | بحث في الأخبار والمعرض والأرشيف والصفحات (حرفان فأكثر) |
| `GET /api/v1/directory/info` | نص الموافقة والمدن المتاحة لنموذج جوال العائلة |
| `POST /api/v1/directory/register` | تسجيل رقم في جوال العائلة (name, phone, email?, city_ids[], consent) |
| `POST /api/v1/directory/remove` | طلب إلغاء اشتراك يراجعه المدير (phone) |

## ملاحظات

- المسارات كلها GET عدا نقطتي جوال العائلة (تسجيل/إلغاء)، وكلاهما محمي بتقييد معدل 5 محاولات كل 15 دقيقة لكل IP، مع نفس تحققات النموذج العام (صحة الرقم، الموافقة الصريحة، منع التكرار برسالة عامة، ولا حذف تلقائي — طلب الإلغاء يراجعه المدير). ملاحظة: الرئيسية تتضمن أيضًا `obituaries_urgent` (الوفيات النشطة) لعرضها كعاجل في التطبيق.
- ترويسة `Cache-Control` مضبوطة لكل مسار (من دقيقتين إلى ساعة حسب طبيعة المحتوى).
- التثبيت كأي إضافة: مجلد `modules/api/` ثم لوحة التحكم → الإضافات → تثبيت وتفعيل.
- تعطيل الإضافة يوقف كل المسارات فورًا دون أثر على بقية النظام.
